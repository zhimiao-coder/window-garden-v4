同站点嵌入 / Same-site embedding

<iframe
  src="viewer.html?model=4"
  title="Interactive Suzhou window studies"
  style="width:100%;height:900px;border:0"
  loading="lazy"
  allow="fullscreen">
</iframe>

嵌入其他网站时，将 src 替换为发布后 viewer.html 的完整 HTTPS 地址。是否允许跨站嵌入取决于托管平台的框架策略。
To embed on another website, use the full HTTPS address of the published viewer.html. Cross-site embedding depends on the host’s frame policy.

模型参数 / Models

model=4：折线木格；5：八角窗框；6：木格扇；0–3：四种母题。中英同屏显示。render=2d 显示静态替代图。
model=4: angular timber lattice; 5: octagonal frame; 6: timber panel; 0–3: motif studies. Chinese and English appear together. render=2d selects a static alternative.

资源 / Resources

请保留完整交付目录，尤其是 vendor/、assets/、sources.html 及字体与代码许可。通过 HTTP 或 HTTPS 访问，直接双击 HTML 文件无法可靠运行模块。
Keep the complete delivery directory, including vendor/, assets/, sources.html and the font and code licenses. Serve through HTTP or HTTPS; opening the HTML file directly cannot reliably load modules.
